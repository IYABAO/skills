# Pulse（工作进度报告）

让 agent 用 30 秒报清楚：现在干什么、今天干了什么、接下来干什么、什么在等用户。

## 第一步：找数据源（自动判断，不用用户选）

### 有项目目录时，直接读项目里的文件

按这个顺序找：

1. **读项目根的 AGENTS.md / CLAUDE.md / README.md**，提取：
   - 任务看板文件路径（active.md / tasks.md / todo.md / kanban / board 等）
   - 日报/周记目录（reviews/ / journals/ / logs/ / daily/ / notes/）
   - 当前主线 / North Star / 本阶段目标
2. **如果上面没说具体路径，在项目根扫常见文件名**：
   - 任务类：`active.md`、`tasks.md`、`todo.md`、`TODAY.md`、`PROGRESS.md`、`kanban.md`、`backlog.md`
   - 日志类：`reviews/daily/<今天>.md`、`journal/<今天>.md`、`notes/<今天>.md`、`logs/<今天>.md`
   - 目标类：`goals/`、`OKR.md`、`roadmap.md`
3. **按找到的文件读内容**：
   - `active.md` → 当前 WIP（正在做）
   - `backlog.md` → 待办池（接下来计划从这挑）
   - `reviews/daily/<今天>.md` → 今天完成、今天阻塞
   - `reviews/weekly/<本周>.md` → 本周目标（对齐主线用）
   - `AGENTS.md` → 当前激活约束、不做什么
4. **文件不存在就明说**："没找到 <文件名>"，不要编进度。

### 没有项目目录时，从对话上下文总结

直接从最近几轮对话和工具调用提炼：
- 最近做了什么操作（改了什么文件、跑了什么命令、生成了什么产出物）
- 当前在推进什么任务
- 哪些事说了但还没落地
- 哪些事卡在用户身上

## 第二步：按固定格式输出（5 段，≤12 行）

```
## 工作状态（YYYY-MM-DD 周X）

**正在做**：
- <任务名>：<一句话说进度，做到哪了、还差什么>
- 没有就写"手头没有进行中的任务"

**今天完成**：
- <条目>
- 没记录就写"今天还没写进度记录"

**接下来计划**：
- <下一件事，一件就够，不要列 5 个让用户选>

**等你**（阻塞在用户动作上的）：
- <任务名>：<等你做什么>
- 没有就写"无"

**一句话**：<今天主线一句话，≤30 字>
```

## 决策规则

### 正在做
- 每个任务用一句话说"做到哪了"，不要复制粘贴任务描述。
- 任务里标了"待用户验收/脱稿/操作/确认"的，移到"等你"段。

### 今天完成
- 文件模式：从今天的日报/日志文件读。文件是空模板或不存在，直接说"今天还没写进度记录"，提醒路径，不要假装今天有产出。
- 对话模式：从最近几轮的产出物总结。

### 接下来计划
- 给一件事，不要列 3-5 个让用户选。
- 文件模式：从 backlog/TODO 挑，**对齐 AGENTS.md/README 里写的当前主线**，不要自己另起方向。
- 对话模式：从最近在推进的方向顺下去。
- 完全没任务时说"手头空了，你说下一件做什么"，不要自己开新项目。

### 等你
- 明确列出卡在用户动作上的事：等验收、等脱稿、等决策、等资源、等建 repo、等配 key。
- 这是 pulse 最有价值的一段——用户最容易忘记自己还有动作要做。

## 硬约束

- **不谎报**：文件里没写、对话里没做的进度不要编。空就说空。
- **不罗列方案**：直接给"接下来计划"一件事。
- **不展开长文**：12 行以内。要分析问题另起任务。
- **不废话开场**：不要"好的我来汇报一下"，直接上格式。
- **路径用绝对路径**：提醒用户补记录时，给完整路径，复制粘贴就能打开。
- **时间感知**：晚上 22 点后不推荐新任务，只说"今天收工，早点休息"。
