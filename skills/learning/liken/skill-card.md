# liken（知音）— Skill Card

- **Type**: Agent Skill
- **Name**: liken
- **Version**: 0.3.0
- **License**: MIT
- **Homepage**: https://github.com/IYABAO/liken
- **Triggers**: `liken` / `知音` + 1~N 个喜欢的东西
- **Language**: 中文为权威版本
- **Requirements**: Python 3.8+，仅使用标准库（urllib/json/argparse），无第三方依赖

## 一句话介绍

输入你喜欢的一个或多个东西（书/电影/音乐/App/咖啡/城市/任意概念），先提炼它们的共性品味维度，再跨域找相似并给出"为什么像"。

> Put a cousin to what you love.

## 核心能力

- **不限领域**：书 / 电影 / 音乐 / App / 咖啡 / 城市 / 工作方式 / 任意概念，按输入动态分块，不预设书影音
- **品味画像**：3-5 个可对照维度（气质/主题/结构/情绪）+ 一个有记忆点的总标签
- **同域≥7**：同领域给 7+ 候选表格（候选｜它是什么｜为什么像｜上手难度｜质量信号），让用户判断抓得准不准
- **跨域每类 3**：你没提到的领域每类 3 个（稳妥 2 + 冒险 1）
- **入门路径**：先从这一个开始 → 再读那个
- **存在性核实**：OpenLibrary（书）/ iTunes Search（音乐）/ Wikidata（电影）/ TVmaze（剧集）
- **诚实标注**：抽象类标 🔮，拿不准标"待核实"，口味不一致分档推荐
- **防回音壁**：同域 7+ 校验样本量，跨域冒险款跳出舒适区

## 何时使用

- 用户说"我喜欢 X、Y、Z，帮我找类似的"
- 想发现新的书 / 电影 / 音乐 / 产品 / 体验
- 想搞清楚"我到底喜欢什么口味"
- 跨域推荐：从一本书的气质联想到一首歌、一款咖啡、一个城市

## 何时不要使用

- 已明确要写的书评 / 影评 / 乐评
- 纯事实查询（这本书讲什么）
- 购物比价、要精确价格/评分排名
- 用户只给了 0 个东西

## 数据来源

| 类型 | API | 说明 |
|---|---|---|
| 书 | OpenLibrary search.json | 核实标题/作者/年份 |
| 音乐 | iTunes Search | 核实曲名/艺人/专辑 |
| 电影 | Wikidata wbsearchentities | 按 description 含 "film" 区分同名 |
| 剧集 | TVmaze search | 备用 |
| 抽象类 | 无 | LLM 推理，标 🔮 |

## 安全说明

- 脚本只读取参数传入的查询词，不访问技能目录外文件
- 无第三方依赖，供应链面仅 Python 标准库
- 无任何凭据、token、PII 上传
- 推荐前必须用脚本核实存在性；核不到不推，拿不准标"待核实"
