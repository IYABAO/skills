# drill（钻取）— Skill Card

- **Type**: Agent Skill
- **Name**: drill
- **Version**: 0.1.0
- **License**: MIT
- **Triggers**: `drill` / `钻取` / `深挖` / `深度学习` / `吃透` + 主题词
- **Language**: 中文为权威版本
- **Requirements**: 联网搜索能力（WebSearch），无第三方依赖

## 一句话介绍

拿到一个词，联网搜权威资源，给你一份从外行到专家的学习地图：学什么、按什么顺序学、每步学到什么程度、去哪学、怎么检验、哪里有坑。

> Drill down to expert level — one word at a time.

## 核心能力

- **8 块固定结构**：定位 → 5-7 维度（标地基/核心/进阶）→ 每维度 L1/L2/L3 三层深度 → 最短学习路径 → 场景化自测题 → 带链接资源地图 → 新手 3 坑 → 专家分水岭
- **联网搜资源**：书/官方文档/综述论文/入门教程/常见误区，每维度 1-2 个，带可点击 URL，标注一手/二手
- **不编造**：搜不到的资源标"待核实"，不凭记忆凑书名/论文名
- **场景化自测**：不考背诵，考"遇到这个场景你怎么判断"
- **跟 formation-learning 分工**：drill 给路线图和资源，formation-learning/knowpitch 负责把知识点 ELI5 讲透，两者配合使用

## 何时使用

- 拿到一个新概念/新领域，想系统学但不知道从哪下手
- 需要一份可执行的学习路线（不是泛泛的书单）
- 想知道"这个领域真正懂行的人和看过几篇博客的人差在哪"
- 已经会用某个工具/方法，想从"会用"走到"能做决策"

## 何时不要使用

- 想让 AI 把某个知识点讲明白（用 formation-learning / knowpitch）
- 纯事实查询（"Python 列表怎么切片"）
- 要写完整文章/报告（用写作类 skill）
- 已经有明确学习材料，只需要总结
